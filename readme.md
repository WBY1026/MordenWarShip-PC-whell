# 现代战舰滚轮切武器脚本

by WBY1026 (银翼战将)

## 概述

该项目旨在为现代战舰PC端添加使用滚轮切换武器的功能，所有判断基于玩家输入，不设计针对游戏的图像识别，内存读取与修改。

脚本基于AutoHotKey2.0实现。

本项目遵守GPL-3.0 (GNU General Public License v3.0)协议

## Overview

This project aims to add the function of using the scroll wheel to switch weapons to the MordenWarShip PC. All judgments are based on player input, and no image recognition, memory reading and modification for the game are designed.



The script is implemented based on AutoHotKey2.0

This project complies with the GPL-3.0 (GNU General Public License v3.0) agreement

## 使用方法

1. 在官网下载AutoHotKey2.0版本（可能需要科学上网）

​	官网网址：www.autohotkey.com

2. 傻瓜式安装，您可以选择安装到您喜欢的位置
3. 找到您的安装目录，并进入 **"您的安装目录" \ v2 \ script** 文件夹下，将该脚本放入文件夹内(或者其他任何地方)
4. 双击该脚本即可启动，若启动失败，请在 **"您的安装目录" \ v2** 中找到 **AutoHotkey64.exe** 将脚本拖到该exe文件上，即可启动
5. 脚本使用方法请看右上角小窗描述
